Django & Python Backend

Sẵn sàng Cloud & Deploy

Tích hợp WhiteNoise nén static files, cấu hình Procfile chuẩn cloud deploy (Render, Railway, Heroku) và xuất bản static cho GitHub Pages dễ dàng.
